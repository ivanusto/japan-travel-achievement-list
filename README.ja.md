# 🇯🇵 日本旅行アチーブメントシステム

アチーブメントシステム、タイルデザイン、和風手帳スタイルを融合させた、個人向けの日本旅行足跡記録・シェアカード生成プラットフォームです。

このシステムはクラウド上で完全に動作します。インストールやファイルのダウンロードは不要で、ブラウザから直接、すべての足跡記録、日本旅行アチーブメント（隠しアチーブメントを含む）を完了できます。

---

## 🌐 オンラインURL

👉 **[いますぐ日本旅行アチーブメントに挑戦する](https://ivanusto.github.io/japan-travel-achievement-list/)**

* 進捗状況はブラウザのローカルストレージ（LocalStorage）に自動保存されるため、プライバシーも安全です。
* いつでも手軽に記録できるよう、このURLをブックマークに追加することをおすすめします！

---

## 🌟 コア機能

1. **統計ダッシュボード**: プレイヤーのレベル（アチーブメント10個ごとに1レベルアップ）や、称号（例：「🌱 日本ビギナー」、「✈ 日本エクスプローラー」、「🏯 日本旅行の神」など）をリアルタイムで計算・表示します。
2. **都道府県足跡マップ**: インタラクティブな地理的グリッドマップ。クリックするだけで足跡を記録し、赤い訪問スタンプを押すことができます。地域ごとの進捗率も動的に反映されます。
3. **レーダーチャート**: 外部ライブラリを一切使用せず、ネイティブCanvasで描画されるため、10個のカテゴリごとの探索状況をスムーズに可視化します。
4. **202のアチーブメントデータベース**: ビギナーから修羅まで6つの難易度があり、アンロックするまで説明が明かされない「Steam風隠しアチーブメント」にも対応しています。
5. **13の解除バッジウォール**: 「🚄 鉄道ファン」、「♨️ 温泉達人」、「🍣 寿司マスター」など、各バッジの解除条件の進捗率を自動で判定します。
6. **シェアカード生成 (PNG)**: ニックネーム、アバター、レベル、バッジウォール、レーダーチャートを自動で合成した、800x1200の高解像度画像を出力します。
7. **テーマ切り替え**: Steamゲーム風のダークテーマと、和紙手帳風のライトテーマに対応しています。
8. **バックアップと復元**: ローカルストレージへの自動保存に加え、進捗データをJSONファイルとしてエクスポート／インポート可能。複数デバイス間での同期も容易です。
9. **バックエンド不要**: 完全静的な単一HTMLファイル。読み込みが非常に速く、データは100%ローカルに保存されるため、プライバシーが守られます。
