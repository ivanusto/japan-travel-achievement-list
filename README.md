# 🇯🇵 日本旅行成就系統 Ultimate Edition

一個結合 **Steam 成就系統**、**Nintendo Switch UI 磁貼美學** 與 **日本傳統手帳風格** 的個人日本旅遊足跡打卡與打卡圖卡生成平台。

---

## 🌟 核心特色

1. **Dashboard 統計看板**: 即時計算玩家等級（每 10 個成就為 1 級）與漸進稱號（例如：`🌱 日本新手`、`✈ 日本探索家`、`🏯 日本旅行神` 等）。
2. **47 都道府縣足跡地圖**: 互動式日本地理網格地圖，點擊可直接打卡並蓋上紅色拜訪印章，動態反饋分區探索率。
3. **Canvas 探索雷達圖**: 原生 Canvas 繪製，無任何外部第三方 JS 庫依賴，完美顯示 10 大分類的探索度。
4. **200 項成就資料庫**: 包含 Beginner 至 Shura 共計六大難度，且支持 **Steam 隱藏成就** 效果，解鎖時可看見驚喜描述。
5. **13 大榮譽徽章牆**: 自動判定如 `🚄 鐵道迷`、`♨️ 溫泉達人`、`🍣 壽司王` 等徽章解鎖進度。
6. **一鍵分享圖卡 (PNG)**: Canvas 自動合成一張包含暱稱、頭像、等級、徽章牆與雷達圖的 800x1200 高解析度名片。
7. **雙主題切換**: 支持 Steam 電玩暗色風與手帳和紙淺色風。
8. **備份與還原**: 本地 LocalStorage 自動存檔，並支持匯出與導入 JSON 進度。
9. **無任何後端**: 完全靜態的單一 HTML 檔案，支持完全離線使用，可秒級部署至 GitHub Pages 或 WordPress。

---

## 🚀 快速開始

### 1. 本地開啟
直接下載 [japan_travel_achievement_list.html](japan_travel_achievement_list.html)，雙擊檔案即可在瀏覽器中直接開啟使用。

### 2. 部署至 GitHub Pages
1. 在 GitHub 建立此專案。
2. 進入專案的 `Settings` -> `Pages`。
3. 將 `Build and deployment` 的 Source 設定為 `Deploy from a branch`。
4. 選擇 `main` 分支並儲存，網頁即會在數分鐘後發布！

---

## 🛠️ 開發與架構

本專案為完全自適應且零外部依賴的 HTML/CSS/JS 應用：
- **字型支援**: 載入 Google Fonts 的 `Outfit` 與 `Noto Sans TC/JP` 系列。
- **音效回饋**: 使用 Web Audio API 原生合成器產生琶音解鎖聲，無音頻檔案載入開銷。
- **粒子特效**: HTML5 Canvas 原生重力與摩擦力演算法粒子煙火。
- **備份**: 提供 `.json` 的備份與恢復，資料完全儲存在使用者的瀏覽器本地，隱私安全無虞。
